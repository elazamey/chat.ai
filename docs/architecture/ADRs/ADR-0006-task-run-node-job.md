# ADR-0006 — Task / Run / Node / Job / ToolExecution

- **الحالة:** Accepted
- **التاريخ:** 2026-09-06

## السياق
خلط "ما يريد المستخدم" مع "وحدة التشغيل" يؤدي لانفجار التصميم عند التوسع.

## القرار
```text
Task (ما يريد المستخدم)
 └── Run (محاولة تنفيذ — قابلة للتكرار بعد الفشل)
      ├── Node (خطوة في الخطة)
      │    └── Job (وحدة تشغيل)
      │         └── ToolExecution (تنفيذ فعلي)
      └── Verification
```

## النتائج
- إيجابي: استئناف/إعادة محاولة على مستوى Run دون إعادة الـTask.
- إيجابي: Idempotency عبر `inputHash` على مستوى ToolExecution.
